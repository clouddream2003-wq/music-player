Library Tools: Audio Normalization

Achieve a consistent volume across your entire offline library regardless of their original production levels using Industry Standard LUFS Normalization (-14 LUFS). Since mobile processing is heavy on battery, we recommend using Termux for this task.

Important: These scripts create optimized copies of your music in a new folder (EncodedMusic). Your original files will remain untouched.

Phase 1: Environment Setup

1. Install Termux from F-Droid.
2. Open Termux and run these commands one by one to prepare your system:
  • termux-setup-storage Grants Termux permission to access your phone's music and storage folders.
  • pkg update -y Updates the list of available software packages to the latest versions.
  • pkg upgrade -y Downloads and installs the latest updates for your current Termux system.
  • pkg install x11-repo -y Adds additional software repositories required for multimedia processing tools.
  • pkg install ffmpeg -y Installs the core engine used to analyze, normalize, and encode your audio files.
  • pkg install gawk -y Provides a high-performance math engine that calculates the precise decimal values needed for the audio limiter.
  • pkg install grep -y Installs the advanced text tool that allows the script to "read" the digital loudness stats from FFmpeg.
  • pkg install termux-api -y Required to make the termux-wake-lock command work, preventing Android from sleeping during processing.

Phase 2: Choose Your Script

Copy the script below based on your preferred output format & paste directly inside Android Termux..

Option A: Opus (High Efficiency)

Recommended for mobile. Best balance of small file size and high audio quality.

#!/bin/bash
termux-wake-lock

INPUT_DIR="/storage/emulated/0/Music/Telegram"
OUTPUT_DIR="$INPUT_DIR/EncodedMusic"
TARGET_LUFS=-10.0
# Peak -0.1 is the absolute maximum digital ceiling
MAX_PEAK_DB=-0.1

mkdir -p "$OUTPUT_DIR"

LIMIT_LINEAR=$(awk "BEGIN { printf \"%.6f\", 10^($MAX_PEAK_DB/20) }")

files=("$INPUT_DIR"/*.mp3)
total_files=${#files[@]}
current=0
SCRIPT_START=$(date +%s)

for input_file in "${files[@]}"; do
    [ -e "$input_file" ] || continue
    ((current++))

    base_name=$(basename "$input_file" .mp3)
    output_file="$OUTPUT_DIR/${base_name}.opus"

    echo "------------------------------------------------"
    echo "[$current/$total_files] Processing: $base_name"
    
    # Get stats
    stats=$(ffmpeg -hide_banner -i "$input_file" -af "loudnorm=I=${TARGET_LUFS}:TP=${MAX_PEAK_DB}:print_format=json" -f null - 2>&1)
    i_meas=$(echo "$stats" | grep -oP '"input_i"\s*:\s*"\K[^"]+')

    [ -z "$i_meas" ] && continue

    gain=$(awk "BEGIN { printf \"%.2f\", ${TARGET_LUFS} - ${i_meas} }")
    echo "Loudness Boost: ${gain}dB | Peak Limit: ${MAX_PEAK_DB}dB"

    # High-Res Internal Workspace + True Peak Protection
    FILTER="aresample=192000,volume=${gain}dB,alimiter=level=true:limit=${LIMIT_LINEAR}:attack=5:release=85,aresample=48000"

    ffmpeg -hide_banner -y -stats -threads 4 -i "$input_file" \
        -af "$FILTER" \
        -c:a libopus -b:a 128k -vbr on \
        -ar 48000 \
        -map_metadata 0 \
        -map 0:a:0 \
        "$output_file"
done

termux-wake-unlock
echo "DONE! Total Processed: $total_files"
