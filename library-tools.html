Library Tools: Audio Normalization

Achieve a consistent volume across your entire offline library using Industry Standard LUFS Normalization (-14 LUFS). Since mobile processing is heavy on battery, we recommend using Termux for this task.

Important: These scripts create optimized copies of your music in a new folder (EncodedMusic). Your original files will remain untouched.

Phase 1: Environment Setup

1. Install Termux from F-Droid.
2. Open Termux and run these commands one by one to prepare your system:
  • termux-setup-storage Grants Termux permission to access your phone's music and storage folders.
  • pkg update Updates the list of available software packages to the latest versions.
  • pkg upgrade Downloads and installs the latest updates for your current Termux system.
  • pkg install x11-repo Adds additional software repositories required for multimedia processing tools.
  • pkg install ffmpeg Installs the core engine used to analyze, normalize, and encode your audio files.

Phase 2: Choose Your Script

Copy the script below based on your preferred output format. Save it as a file (e.g., normalize.sh) and run it with bash normalize.sh.

Option A: Opus (High Efficiency)

Recommended for mobile. Best balance of small file size and high audio quality.

#!/bin/bash
INPUT_DIR="/storage/emulated/0/Music"
OUTPUT_DIR="/storage/emulated/0/Music/EncodedMusic"
TARGET_LUFS=-14
MAX_TRUE_PEAK_DB=-1.5
OUTPUT_SAMPLE_RATE=48000
OUTPUT_CHANNELS=2
OPUS_BITRATE="128k"

mkdir -p "$OUTPUT_DIR"
LIMIT_LINEAR=$(awk "BEGIN { printf \"%.6f\", 10^(${MAX_TRUE_PEAK_DB}/20) }")

for input_file in "$INPUT_DIR"/*.mp3; do
    [ -e "$input_file" ] || continue
    base_name=$(basename "$input_file" .mp3)
    output_file="$OUTPUT_DIR/${base_name}.opus"

    echo "Analyzing: $base_name..."
    stats=$(ffmpeg -hide_banner -i "$input_file" -af "loudnorm=I=$TARGET_LUFS:TP=$MAX_TRUE_PEAK_DB:print_format=json" -f null - 2>&1)
    input_i=$(echo "$stats" | grep -oP '"input_i"\s*:\s*"-?\d+\.?\d*"' | cut -d ':' -f2 | tr -d ' "')

    if [ -z "$input_i" ]; then continue; fi
    gain=$(awk "BEGIN { printf \"%.2f\", $TARGET_LUFS - $input_i }")

    ffmpeg -hide_banner -y -i "$input_file" -af "volume=${gain}dB,alimiter=limit=${LIMIT_LINEAR}:attack=5:release=50:level=disabled" -ar "$OUTPUT_SAMPLE_RATE" -ac "$OUTPUT_CHANNELS" -c:a libopus -b:a "$OPUS_BITRATE" -vbr on -compression_level 10 "$output_file"
done
echo "Done: All files processed."

Option C: MP3 (Maximum Compatibility)

Ensures your music plays on any device or legacy player.

#!/bin/bash
INPUT_DIR="/storage/emulated/0/Music"
OUTPUT_DIR="/storage/emulated/0/Music/EncodedMusic"
TARGET_LUFS=-14
MAX_TRUE_PEAK_DB=-1.5
OUTPUT_SAMPLE_RATE=48000
OUTPUT_CHANNELS=2
QUALITY_MODE="192k" # Edit to 320k for higher quality

mkdir -p "$OUTPUT_DIR"
LIMIT_LINEAR=$(awk "BEGIN { printf \"%.6f\", 10^(${MAX_TRUE_PEAK_DB}/20) }")

if [[ "$QUALITY_MODE" =~ ^[0-9]+k$ ]]; then
    MP3_OPTS="-b:a $QUALITY_MODE"
else
    VBR_QUALITY=${QUALITY_MODE#V}
    MP3_OPTS="-q:a $VBR_QUALITY"
fi

for input_file in "$INPUT_DIR"/*.mp3; do
    [ -e "$input_file" ] || continue
    base_name=$(basename "$input_file" .mp3)
    output_file="$OUTPUT_DIR/${base_name}.mp3"

    stats=$(ffmpeg -hide_banner -i "$input_file" -af "loudnorm=I=$TARGET_LUFS:TP=$MAX_TRUE_PEAK_DB:print_format=json" -f null - 2>&1)
    input_i=$(echo "$stats" | grep -oP '"input_i"\s*:\s*"-?\d+\.?\d*"' | cut -d ':' -f2 | tr -d ' "')

    if [ -z "$input_i" ]; then continue; fi
    gain=$(awk "BEGIN { printf \"%.2f\", $TARGET_LUFS - $input_i }")

    ffmpeg -hide_banner -y -i "$input_file" -af "volume=${gain}dB,alimiter=limit=${LIMIT_LINEAR}:attack=5:release=50:level=disabled" -ar "$OUTPUT_SAMPLE_RATE" -ac "$OUTPUT_CHANNELS" -c:a libmp3lame $MP3_OPTS "$output_file"
done
echo "Done: All files processed."
